# 📰 Fake News Detection API

An AI-powered backend system that detects whether a news article is **REAL or FAKE** using a machine learning pipeline.

---

## 🚀 Features

- FastAPI-based REST API
- Machine Learning model (scikit-learn pipeline)
- Real-time text analysis
- Clean and modular architecture

---

## 🧠 Tech Stack

- FastAPI
- Scikit-learn
- Joblib
- Python
