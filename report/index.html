Executive Overview

The Hybrid Fake News Detector v5.0 (Phase 6) represents the culmination of a rigorous 6-phase machine learning enhancement cycle. Designed for highly volatile environments, the system solves the typical vulnerabilities of standard models—namely overfitting and silent domain drift—by establishing an independent three-layer verification pipeline. Operating across a Statistical ML layer, an AI semantic checker, and real-time news consensus scrapers, the system provides clinical objectivity. This report breaks down the foundational architecture, handcrafted stylometric features, calibrated ensemble classifiers, cosine OOD routing mechanics, and database-backed monitors.

Forensic Ingestion & Translation Normalization

Stylometric classifiers are fragile: parsing a machine-translated article directly alters structural footprints (such as vocabulary diversity, average sentence lengths, and pronoun ratios). The system bypasses this by utilizing a Global Translation Matrix powered by Gemini. Translation occurs prior to meta-feature computation, guaranteeing that articles written in foreign scripts are structurally and semantically normalized without diluting critical stylometric markers.

Stacking Ensemble & Isotonic Calibration

Combining five diverse estimators with calibrated voting schemas for reliable confidence scores.

The Stacking Architecture

Instead of pinning system performance on a single classification style, the pipeline trains five independent base classifiers covering divergent mathematical paradigms:

  • Logistic Regression (LR): Standard regularized linear baseline.
  • Random Forest (RF): Bagging ensemble mapping meta-feature bounds.
  • SGD Classifier (SGD): Elastic-net linear classifier for sparse spaces.
  • Linear SVC: Support vector machine isolating high-dimensional planes.
  • LightGBM: Tree-boosting estimator capturing complex boundaries.
Isotonic Calibration: Aggregated base predictions are combined via a secondary Logistic Regression meta-learner and calibrated using Isotonic Regression. This translates raw boundary margins into honest, mathematically rigorous confidence probabilities.

OOD Safeguards & Production Telemetry Monitoring

Protecting the pipeline from silent domain drift and mapping operational database health in production.

Out-of-Distribution (OOD) Routing

Unfamiliar scientific domains, breaking news events, or foreign texts generate high OOD ratings. The OOD score $S_{ood} \in [0, 1]$ is computed as:

S_{ood} = 0.40 \cdot D_{cosine} + 0.35 \cdot (1 - O_{vocab}) + 0.25 \cdot H_{structural}
  • $D_{cosine}$: Cosine distance to precomputed training TF-IDF centroid.
  • $O_{vocab}$: Overlap ratio against training vocabulary.
  • $H_{structural}$: Structural length anomalies and non-Latin character maps.

Dynamic Weight Shifting

When $S_{ood} > 0.30$, the system shifts weight away from the statistical ML layer to Google Gemini AI semantic fact-checking and GNews temporal web corroboration:

OOD Rating ML Weight Gemini Weight Web Weight
$\le 0.30$ (Normal) 50% 30% 20%
$0.60$ (Moderate) 30% 42% 28%
$\ge 0.80$ (Severe) 20% 48% 32%

Active Production Telemetry Monitor

All queries, predictions, confidence ratings, and OOD metrics are logged in real-time to an active SQLite database (analysis_history.db). A monitoring daemon continuously evaluates rolling 30-day windows to trigger automated alerts:

⚠️ Prediction Drift: Triggered if the FAKE-to-REAL classification ratio shifts by more than 20% over 7 days.
⚠️ OOD Spike: Triggered if rolling average OOD score spikes by 30%, suggesting current news cycles have drifted away from the training baseline.
⚠️ Confidence Decay: Triggered if rolling calibrated confidence falls below 70%, notifying administrators that a model retrain cycle is required.
